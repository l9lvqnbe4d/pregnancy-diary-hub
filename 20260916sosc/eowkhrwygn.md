# 吃饭噎着、喝水噎着  这究竟是怎么回事？

> 更新时间：2026-09-16 (UTC+8)

在生活中经常听到一些爱美的女生

说：哎，减肥真难，喝口凉水都会长肉！

所以很多时候就不喝水

宁愿渴了也不喝

**最近，却有人喝凉水噎着了，这到底是怎么回事？**

小编朋友的爷爷，身体一直很健康，平时爱喝滚烫的热水、爱吃刚做好的热乎乎的饭菜。前段时间，老人突然发现自己在吃东西的时候总是噎着，却没有太在意，以为是自己吃饭太快了，才会这样。

直到前几天发现自己连喝水都会噎着的时候，才意识到事情的严重性。于是，在家人的陪同下，来到河北省人民医院进行检查。检查结果为：食道癌！

老人很纳闷，平时自己很少生病啊，为什么突然就会得了食道癌？

专家告诉我们：人体的食管壁由粘膜组成，只能耐受50℃左右的温度，热水的温度往往在70℃左右，长期饮用容易烫伤食管粘膜。日积月累食管粘膜被反复烫伤，很可能诱发食管癌。

由于老人年纪大，不能耐受手术，于是在河北省人民医院肿瘤一科进行了近两个月的放疗治疗后，病情有所好转，现在已经出院回家。

回家后，老人再也不喝滚烫的热水，吃饭的时候也会等饭菜不那么烫的时候才吃。

**那么，为了防止食道癌的发生，我们应该如何预防呢？**

1. 不吃霉变食物，少吃或不吃酸菜；

2. 不要吃过烫的食物，不要进食过快；

3. 不要过量饮烈性酒，以减轻对食管黏膜的刺激；

4. 常服用维生素C，减少胃内亚硝胺的形成。

所以，为了自己的身体健康，一定要养成良好的生活习惯，远离食道癌。如果您有这方面的困扰，可以拨打**肿瘤一科电话：85989933（病区）/ 85988741（医生办公室）**进行免费咨询。
