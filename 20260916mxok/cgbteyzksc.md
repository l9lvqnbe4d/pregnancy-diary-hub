# 眼科、神经内科在全国罕见病科普大赛中荣获佳绩

> 更新时间：2026-09-16 (UTC+8)

近日，首届“闰笛杯”全国罕见病科普大赛获奖名单揭晓。我院眼科参选代表作品“重瞳，帝王之相乎”获得大赛图文组二等奖，神经内科参选代表作品“了解多系统萎缩，早识别早诊断”获得大赛视频组三等奖。

此次大赛由中国罕见病联盟、中华医学会罕见病分会、全国罕见病诊疗协作网办公室等全国27家罕见病诊疗协作网医院联合举办。全国各医疗单位提交作品550余份，涵盖240余种罕见病，评审历时5个月。

“重瞳，帝王之相乎”由眼科副主任夏媛玲、副主任医师陈炜及其研究生共同创作。该作品围绕应用现代医学对常染色体显性遗传性疾病Axenfeld-Rieger综合征——“重瞳”作了全面讲解。“了解多系统萎缩，早识别早诊断”由神经内科主任贺电、护士长袁平乔、医生彭玉洁等共同创作。该作品以不同的临床症状为视角，对多系统萎缩(multiple system atrophy，MSA）疾病作科普。两个作品以直观、生动、形象的方式呈现出疾病全貌，将现有已知的信息进行有效传递，帮助更多罕见病患者获益，提升公众对该疾病的认识。

据悉，多年来，罕见病群体长期面临确诊难、误诊多、易延误诊疗的问题，提出“罕见病”概念的真正意义并非强调病例稀少，而是提醒我们忽视“罕见”所造成的后果是未被满足的巨大医疗需求。通过罕见病科普大赛，联合更多的医生做罕见病患者和家属的贴心人、罕见病患者救治的引路人、罕见病科普推广的代言人，共同科普罕见病，为罕见发声，让疾病知识深入人心，让罕见生命不再孤单，让罕见病群体走进公众的视野，获得社会的接纳与帮助。
