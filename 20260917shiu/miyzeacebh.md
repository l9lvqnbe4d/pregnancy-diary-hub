# 奶块堵奶怎么用6步按摩法轻松快速的揉开？

> 更新时间：2026-09-17 (UTC+8)

2月28号生下的二胎，之前一胎喂养都是正常的，从来没有出现过奶块堵奶的情况，但二胎这里出现了，我怀疑就是吃太多营养好的食物了。我自己尝试过用吸奶器吸通，但是太痛了，所以没有吸出来，看网上有奶块堵奶的6步按摩法就想尝试尝试，该怎么按摩才能快速轻松的揉开奶块？

奶块堵奶想要轻松快速的揉开，只需要6步，首先就是用热毛巾热敷乳房，帮助疏通乳腺，然后用大拇指和食指在乳晕外侧将乳晕向外推，同时挤捏乳头根部。之后在乳房上放上一些润滑油，然后双手由乳房四周向乳头方向推抚，一只手手指抓住乳房，一抓一松，轻轻揉捏，另一只手揪动乳头。然后用拇指、食指、中指按摩挤压乳头，将奶水排出，最后借助吸奶器将奶水吸出。

一般妈妈生产完后一般会有奶水，如果在涨奶的时候没有把乳汁全部吸出来，等到后面再一次涨奶的时候，乳汁就会被困在乳管里很难流出来了，久而久之形成奶结。这种时候就可以采用6步按摩法轻松快速的将年块揉开，具体操作如下：

- 1. 第一步：在喂奶之前或者吸奶器之前使用热毛巾敷，可以帮助疏通乳腺；
- 2. 第二步：大拇指和食指放在乳晕外侧，用力将乳晕向外推，退的同时，挤捏乳头的根部；
- 3. 第三步：在乳房上撒上一些润滑油，然后双手由乳房四周向乳头方向推抚50-100次；
- 4. 第四部：一个手五指着力，将乳房抓起，轻轻揉捏，一抓一松，另一只手揪动乳头；
- 5. 第五步：用拇指、食指、中指三指打圈按摩连续做五分钟以上，将奶水排出；
- 6. 第六步：按摩结束后用吸奶器将奶块吸出，吸的时候可能有点痛，需要宝妈坚持一下。
哺乳期堵奶应该是很多宝妈都遇到过的，在奶块堵奶按摩揉开后很多女性都会出现奶水减少的情况，这时候堵奶后如何追奶就尤为关键了，大家可以让宝宝多多吮吸，每次喝奶就将奶水喝完，这样很快奶量就会恢复正常。
